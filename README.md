# DriftIris

DriftIris is a distributed, real-time data processing engine for scalable, microservices-based platforms.

DriftIris is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/DriftIris.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DriftIris is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
